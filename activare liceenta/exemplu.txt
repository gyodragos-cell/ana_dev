### 🔄 Cum Functioneaza:

#### __Pasul 1: Tu generezi licenta (pe calculatorul tau)__

```bash
# Intri in folderul proiectului tau
cd C:\Users\billy\Desktop\ANA_MAX_GitHub_Release

# Generezi licenta pentru un client
python generate_license.py --email client@gmail.com --days 30
```

__Ce se intampla:__

- Scriptul ruleaza LOCAL la tine
- Primesti o cheie lunga (ex: `Z0123456789ABCDEF...`)
- Aceasta cheie este LICENTA

#### __Pasul 2: Trimite cheia clientului__

Clientul primeste:

1. Cheia de licenta (text lung)
2. Instructiuni simple:

```javascript
1. Descarca ANA MAX de pe GitHub
2. Deschide terminal in folderul proiectului
3. Ruleaza: python activate_license.py --key CHEIA_PRIMITA_DE_LA_TINE
4. Gata! Ai acces Pro pentru 30 de zile
```

#### __Pasul 3: Clientul activeaza (pe calculatorul LOR)__

```bash
# Clientul ruleaza pe calculatorul lor:
python activate_license.py --key Z0123456789ABCDEF...

# Rezultat: ✅ Licenta activata cu succes!
```

### 💡 Important de Inteles:

1. __Tu ai `generate_license.py`__ - doar TU il folosesti (e la tine in proiect)
2. __Clientul are `activate_license.py`__ - il primeste cand descarca proiectul de pe GitHub
3. __Nu trebuie sa copiezi nimic__ - totul e deja in proiectul de pe GitHub
4. __Licenta e doar un text__ - il poti trimite prin email, WhatsApp, etc.
