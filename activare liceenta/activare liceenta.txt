🔐 Cum Activezi Licenta Pro
Pentru Utilizatori:
Metoda 1: Folosind scriptul activate_license.py


python activate_license.py --key CHEIA_TA_DE_LICENTA
Metoda 2: Folosind comanda Python


python -c "from core.license_manager import LicenseManager; m = LicenseManager(); m.activate('CHEIA_TA_DE_LICENTA')"
Metoda 3: Verificare status licenta


python -c "from core.license_manager import get_license_manager; print(get_license_manager().get_license_info())"
Pentru Tine (Generator Licente):
Cand vrei sa creezi o licenta pentru un utilizator:


python generate_license.py --email user@example.com --days 30
Parametri:

--email - Email-ul utilizatorului
--days - Durata licentei (30 zile, 90 zile, 365 zile etc.)
--trial - Pentru licenta trial (max 7 zile)
--quiet - Afiseaza doar cheia (fara alte mesaje)
Exemplu Complet:
Generezi licenta:

python generate_license.py --email client@example.com --days 30
Primesti o cheie de genul:

Z0123456789ABCDEF... (cheie lunga criptata)
Trimite cheia clientului + instructiuni:

1. Copiaza cheia de licenta
2. Ruleaza: python activate_license.py --key CHEIA_PRIMITA
3. Reporneste serverul ANA MAX
Clientul activeaza si poate folosi tool-urile premium.
Verificare Licenta Activa:

python -c "from core.license_manager import get_license_manager; m = get_license_manager(); print('Pro:', m.is_pro()); print('Info:', m.get_license_info())"
Important:
Licenta este legata de calculatorul unde a fost activata
Nu se poate transfera pe alt calculator fara dezactivare
La expirare, tool-urile premium devin din nou blocate
Fisierul .license contine datele criptate (nu il sterge!)
