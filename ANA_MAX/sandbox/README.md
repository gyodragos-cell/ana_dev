# ANA MAX Sandbox

This folder is the quarantine area for ad-hoc experiments, quick scripts,
temporary prompts, and one-off test outputs created while working in the
mother lab.

Rules for agents:

- Put scratch scripts here instead of the repository root.
- Keep validated behavior in `ANA_MAX/core/`, `ANA_MAX/tools/`, or `tests/`.
- Do not sync this folder to the public release.
- Do not store secrets, tokens, private screenshots, or raw chat archives here.
- If a sandbox experiment becomes useful, promote only the cleaned logic and
  focused tests.
