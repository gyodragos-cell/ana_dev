# ANA MAX Failure Playbook

## Common Failure Modes

- Invalid tool output.
- Timeout.
- Misrouting.
- Policy block.
- Repeated tool failure.

## Diagnostic Steps

1. Read normalized error.
2. Check policy decision.
3. Check health and profiling metrics.
4. Review audit metadata.
5. Use auto-repair suggestions.

## Repair Strategies

- Retry with smaller output.
- Switch to backup tool.
- Suggest patch text.
- Disable broken tool temporarily.
