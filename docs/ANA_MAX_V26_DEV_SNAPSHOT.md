# ANA MAX v26 Dev Snapshot

## New Components

- Internal reasoning summaries
- Self-evaluation critic
- Long-horizon task planning
- Goal manager
- Agent negotiation
- Advanced session lifecycle
- Human feedback hooks
- Advanced observability events

## Known Limitations

- Reasoning is private metadata only, not external chain-of-thought logging.
- Real distributed execution is not implemented.
- Persistence is dev-local and policy-gated.

## Lab-Only Features

- Session archives
- Human feedback datasets
- Internal reasoning graphs
- Private evaluation traces
