# Identity Surface Check Example

## Purpose

Show how ANA keeps the active lab and extension identity Codex-first without
promoting external tools or comparative branding.

## Command

```powershell
python ANA_MAX/dev_artifacts/scripts/ana_identity_surface_check.py --no-write
```

## Sanitized Result Summary

```text
ANA Identity Surface: PASS files=10 violations=0 missing_required=0
```

## What This Proves

- Active identity files mention Codex and ANA MAX.
- Active docs and extension copy do not contain "Codex vs X" positioning.
- External tool names are not used as promotion in active lab surfaces.
- Retired tool names are allowed only when clearly framed as retired or
  historical.

## Limitation

This scans active identity files only. Historical checkpoints, archives, old
reports, and sandbox material may still contain older names.
