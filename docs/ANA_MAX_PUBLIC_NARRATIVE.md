# ANA MAX Public Narrative

ANA MAX is a local AI runtime for agents that need to observe before they act.
It combines project awareness, tool routing, safety policies, observability,
and human review into one operating model.

## Positioning

ANA MAX is not just a tool list. It is an agent runtime contract for local
workstations and private QA labs.

## Key Features

- Observation-first workflows.
- Policy-gated execution.
- Adaptive routing.
- Memory and session concepts.
- Multi-agent planning roadmap.

## Lab-Only

Private memory, logs, sessions, optimization snapshots, and real distributed
runtime experiments stay lab-only.
