# ANA MAX Limitations

## Cannot Do

- Guarantee safe behavior without policy review.
- Execute private or external systems without permission.
- Publish private memory or lab data safely without redaction.

## Known Risks

- Misrouting.
- Over-broad tool permissions.
- Noisy outputs.
- Session state leakage if isolation is misconfigured.

## Non-Goals

- Fully autonomous public release writes.
- Secret storage in public repos.
- Unapproved network or subprocess execution.
